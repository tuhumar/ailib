# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2024-03-14

### Added
- Initial version of the `ailib` library.
- `StdinBackend` and `FileBackend` backends.
- Core functions: `ask`, `ask_json`, `decide`.
- Support for logging with file rotation.
- Configuration via environment variables.
- Support for Context Manager to switch backends.
- Resilient JSON parsing for AI responses.
